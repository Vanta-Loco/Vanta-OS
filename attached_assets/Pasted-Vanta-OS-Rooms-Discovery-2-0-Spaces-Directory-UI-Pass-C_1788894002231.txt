Goal
Make /rooms feel like the entrance to Vanta’s creative spaces rather than a basic list of Rooms.
A Member should quickly understand:
what each Room represents
who is there
what is being created there
whether they already belong
where they want to enter next
1. Strong Rooms directory header
Present:
VANTA ROOMS
with restrained copy such as:
Creative spaces inside the Vanta network.
Preserve existing Vanta styling.
Do not make it look like Discord server discovery.
2. Official Room cards
Give each existing Room a stronger spatial identity.
Existing official Rooms include:
Music
Fashion
Visual
Media
Music and Fashion already have rendered environment artwork.
Use those existing environment assets prominently where appropriate.
Do not regenerate or redesign those assets.
Visual and Media should use their current safe/default treatment until their environments are designed later.
3. Room status
Where real data is already available, show compact information such as:
member count
Work count
active Marketplace listing count
joined state
Example:
18 MEMBERS / 7 WORKS / 3 LISTINGS
Real values only.
If a count is not available through existing safe APIs, omit it rather than inventing it.
Do not create expensive new backend aggregation architecture during this UI stage.
4. Joined state
Make Rooms the Member already belongs to immediately identifiable.
Use a restrained:
JOINED
or:
MEMBER
treatment.
Primary action for joined Rooms:
ENTER ROOM
For Rooms not yet joined:

or existing appropriate join flow.
Do not automatically join Members from the directory.
5. Categories
Preserve or improve the existing Room category filtering.
Keep it lightweight.

6. Activity hints
Where existing real data allows it, surface subtle indicators that a Room contains:
Creator Work
Marketplace listings
Members
Do not display fake “active now” counts.
Do not claim real-time presence unless real-time presence exists.

Rooms should visually reinforce that creators live across the ecosystem.

indicator or a limited preview.
Do not build another Creator Directory inside /rooms.
/creators remains the Creator Discovery system.

followed by the real Room directory.
