Vanta Member System — Phase 1, Stage 1: User Management Backend Foundation ONLY
Continue in Free Mode. Do not switch to Power.
Vanta already has an existing Express server, PostgreSQL database, users table, login/register flow, X-User-Token Member authentication, Passport system, Creator Profiles, Rooms, Marketplace and Admin authentication.
Do NOT create another authentication system or another server.
The goal of this phase is to turn the existing registered-user infrastructure into a real centralized Vanta Member Management system for Admin.
The current Admin User Management screen is only a placeholder saying the Vanta user/profile system does not exist yet.
Replace that foundation with real backend capabilities using the existing users and related Vanta data.

existing users table/schema
registration/login implementation
current Member token auth
Admin authentication
Passport relation to user_id
Creator Profile relation to user_id
existing account/role/status fields if any
