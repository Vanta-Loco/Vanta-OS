Expand the existing working Admin system so it covers the full Vanta ecosystem.

The Admin login and session now work correctly. Do not rebuild or replace authentication.

The current issue is that the Admin dashboard does not include management access for all Vanta apps and content types.

Main requirement

Use one central Admin dashboard for the entire Vanta Cold platform.

Do not create separate admin login systems for Stonerism, World, Vault or any other app.

The same authenticated admin session must work across all Vanta routes and apps.

Admin dashboard sections

Audit the current project and add navigation and management sections for all existing supported areas:

* Main Blog
* Blog Posts
* Music
* Releases
* Vault
* Vault Tracks
* Worlds
* World Alpha settings and content
* Stonerism
* Stonerism Articles
* Stonerism Reviews
* Black Index
* Users and Profiles
* Developer Logs
* Early Access Waitlists
* Upcoming App Teasers
* Site Settings

Only add editing controls for functionality that currently exists in the project. Do not fabricate management tools for data that does not yet exist.

Stonerism

Add Stonerism to the central Admin dashboard.

The admin should be able to manage existing Stonerism content, including where supported:

* Create articles
* Edit articles
* Publish or unpublish articles
* Delete articles with confirmation
* Manage reviews
* Moderate user-submitted content
* Manage featured content
* Manage categories, strains, growers or locations if those models already exist

Reuse the existing Stonerism database and routes.

Do not create a second Stonerism database or authentication system.

Vault and Music

Add management access for:

* Uploading tracks
* Editing track details
* Removing tracks with confirmation
* Updating cover art
* Changing track order where supported
* Managing releases
* Setting published or draft status
* Choosing whether a track may play on Vanta Radio

Preserve all existing music files and metadata.

World Alpha

Do not rebuild or expand the game during this task.

Add a lightweight World Admin section for existing configurable data only, such as:

* World status
* Alpha availability
* Featured image
* Description
* Current version
* Maintenance message
* Radio enabled or disabled
* Available Vault tracks
* Known issues
* Developer notes

Do not attempt to build a full visual game editor.

Black Index

Add an Admin section for managing what public content types Black Index may search.

Allow the admin to enable or disable indexing for:

* Blog posts
* Music
* Releases
* Stonerism
* Public user profiles
* Developer Logs
* App teaser pages

Never allow private information, passwords, emails, waitlist records, admin notes or draft content to appear in public search.

Users and Profiles

* Search users

* Assign or remove supported roles
* Suspend or reactivate accounts
* Remove inappropriate public profile content
* View join date
* View app interests

Protect role changes and destructive actions.
