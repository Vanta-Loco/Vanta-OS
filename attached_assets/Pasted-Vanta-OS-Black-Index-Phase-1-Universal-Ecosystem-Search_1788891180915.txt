Vanta OS — Black Index Phase 1: Universal Ecosystem Search
Continue in Free Mode. Do not switch to Power.
Vanta Guide is complete and working.
This task is ONLY to build Black Index Phase 1 as a real universal search layer across existing Vanta data.
Do not build AI/chat functionality yet.
Do not modify authentication architecture, production infrastructure, storage, database relationships, or unrelated systems.
Core distinction
Vanta Guide helps Members understand Vanta and navigate the OS.
Black Index helps Members find real things that exist inside Vanta.
Black Index should answer:
Who?
What?
Where?
using actual ecosystem data.
