Vanta OS — Phase 1 UI: Home Dashboard / Ecosystem Hub
Continue in Free Mode.
Do not switch to Power.
This task is primarily frontend/UI using existing APIs and systems.
Do not create new backend architecture unless a verified missing read endpoint makes one small addition necessary.
Goal
Turn the main authenticated Vanta OS home experience into a connected Vanta Dashboard that immediately shows the Member:
who they are
where they belong
what they are making
what is happening around Vanta
The page should make Vanta feel like one creative operating system rather than a collection of separate apps.
Preserve the existing Vanta OS aesthetic and navigation.
1. Member identity header
At the top of the authenticated dashboard, show the current Member identity using existing Passport/Creator data where available.
Include:
@username
Passport level
Creator display name if Creator Profile exists
Certified Creator treatment only when actually certified
Use a restrained OS/status-panel presentation.
Do not expose private account data.
2. Main Vanta modules
Present the core apps clearly:
Passport
Rooms
Creator / Work
Marketplace
Vanta Play
Transmission
Vault
World
Each should feel like an actual Vanta OS module rather than generic website cards.
Use the existing route destinations.
Do not duplicate existing navigation unnecessarily.
3. “Your Rooms”
Add a compact section showing Rooms the current Member has joined.
Use existing Room data/auth behavior.
Show up to a small useful number such as 3–4.
Each Room should show:
Room name
category
environment thumbnail/background treatment where already available
quick Enter Room action
If the Member has joined no Rooms:
You haven't entered any Rooms yet.
Link to /rooms.
Do not create fake memberships.
4. “Your Work”
If the Member has a Creator Profile, show a small preview of their existing Creator Work.
Prefer:
Featured Work first
then newest Work
Maximum 3 preview items.
Include:
title
type
thumbnail or existing placeholder
Link to:
/creator
If they have a Creator Profile but no Work:
Your archive is empty.
Add:
Add Work
If they do not have a Creator Profile, use a subtle:
Activate Creator Profile
CTA.
5. Marketplace preview
Show a compact feed of current real Marketplace listings.
Do not invent listings.
Show a small number such as 3–4.
Include:
listing title
category
creator identity
price type / price where supplied
Add:
Open Marketplace
6. Transmission preview
Show a compact preview of recent real Transmission/editorial content using the existing public post APIs.
Do not build a new blog system.
Use:
cover image where available
post title
date/category where available
Clicking opens the existing post.
7. Vanta Play preview
Add a small Vanta Play section using existing real games.
Show up to 2–3 upcoming/open games.
Include:
game title/location
date/time if present
participant count
CTA:
Find a Game
Do not modify Play logic.
8. World status
Give Vanta World a more intentional presence on the dashboard.
Use a small status/module panel such as:
WORLD ALPHA
Enter the city
Link to the existing World route.
Do not modify the 3D World itself in this task.
9. Guest behavior
Do not destroy the existing boot/login experience.
Guests should still see the appropriate unauthenticated entry flow.
The connected dashboard should appear after Member authentication.
10. Visual direction
The dashboard should feel like:
underground desktop OS
early-2000s console/computer interface
creative control center
Vanta system terminal
Avoid:
generic SaaS dashboard
corporate analytics UI
giant colorful modern app cards
fake graphs
Use existing Vanta visual language:
dark surfaces
restrained borders
CRT/Y2K influence
system labels
compact metadata
intentional hover/focus states
11. Responsive behavior
Desktop:
modular grid/layout
Mobile:
single-column or compact two-column where appropriate
no horizontal overflow
modules remain easy to tap
12. Data discipline
Use real existing data only.
Never create fake:
users
work
listings
posts
games
room memberships
Proper empty states are better than fake activity.
Preserve
Do not modify:
authentication
Member sessions
Admin sessions
suspension
database schema
media infrastructure
Rooms behavior
Marketplace behavior
Creator Work CRUD
Vanta Play logic
Transmission editor
Vault
World engine
Verification
Run:
npm run check
npm run build
git diff --check
Manually verify:
Guest boot/login still works.
Sign in as a Member.
Dashboard loads real identity data.
Joined Rooms appear correctly.
Creator Work preview behaves correctly.
Marketplace shows only real listings.
Transmission shows real content.
Vanta Play preview uses real games.
Every module links to the correct existing route.
Empty states work for a newer Member.
Mobile layout has no overflow.
Stop after the Vanta Dashboard is complete.
Do not begin another backend or infrastructure stage.
