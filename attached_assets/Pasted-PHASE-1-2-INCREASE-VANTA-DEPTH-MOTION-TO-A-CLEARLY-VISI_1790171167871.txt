PHASE 1.2 — INCREASE VANTA DEPTH MOTION TO A CLEARLY VISIBLE LEVEL
The parallax system is confirmed to be functioning technically, but the current live values are still too subtle to perceive as a meaningful visual effect.
Current mobile values are approximately:
- background Y: 0 → -48px
- foreground Y: 0 → +16px
- scale: about 1.02 → 1.045
These values are too restrained for the Vanta visual concept.
The goal now is not to redesign anything or add Phase 2 features. The goal is to make the existing Phase 1 depth effect clearly visible and cinematic.
Increase the motion so that a normal user immediately notices that the Vanta environment is moving at a different depth from the webpage while scrolling.
Target approximately:
MOBILE
background translateY: 0 → -90px to -120px
foreground translateY: 0 → +30px to +45px
hero scale: about 1.10 at entrance → around 1.02 by exit

DESKTOP
background translateY: 0 → -140px to -180px
foreground translateY: 0 → +45px to +70px
hero scale: about 1.12 → 1.01
Tune within these ranges according to the current layout and cropping.
Also:
- Make the background and foreground move at clearly different rates.
- Keep the text/UI comparatively stable.
- Preserve smooth easing.
- Do not create horizontal movement large enough to reveal empty edges.
- Keep enough overscan/scale on imagery so movement never exposes the image bounds.
- Keep navigation, content, routes, buttons, typography, and imagery unchanged.
- Do not add glitches, environmental states, TV effects, or WebGL yet.
Strengthen the atmosphere slightly too:
- make haze/light drift visible
- keep it slow and cinematic
- no aggressive flicker
The hero should now feel like:
the camera is moving through a Vanta environment while the webpage remains easy to use.
Test using real live scrolling, not screenshots.
After implementation report:
1. final mobile motion values
2. final desktop motion values
3. whether the movement is visibly noticeable in live preview
4. whether any cropping/overflow issues appeared
5. files changed
Do not proceed to Phase 2.
