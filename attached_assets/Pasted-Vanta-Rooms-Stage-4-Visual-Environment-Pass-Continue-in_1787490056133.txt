Core visual concept
Vanta Rooms should feel like entering an actual creative space rather than opening a generic community page.
Preserve the existing Feed / Members / Work / Listings functionality, but visually frame official Rooms as environments.
For this first pass, focus only on the official Fashion and Music Rooms.
Fashion Room — industrial warehouse
Give the official Fashion Room a visual identity inspired by an underground fashion warehouse / creative production space.
Visual cues can include:
concrete / industrial surfaces
garment rack silhouettes
stacked boxes / crates
large mirrors
cutting/work tables
pinned moodboards / contact sheets
photo backdrop / flash-studio feeling
warehouse windows or loading-bay influence
subtle distressed textures
It should feel like designers, stylists, models and photographers actually work there.
Do not make it look like an e-commerce store.
Music Room — bedroom producer studio
Give the official Music Room a different environment inspired by a messy late-night bedroom studio / underground producer room.
Visual cues:
studio monitors
computer / CRT glow
MIDI keyboard
microphone
cables
posters
CDs / records
speakers
dim practical lighting
early-2000s/Y2K bedroom-studio influence
It should feel personal, lived-in and creative rather than like a professional commercial recording studio.
