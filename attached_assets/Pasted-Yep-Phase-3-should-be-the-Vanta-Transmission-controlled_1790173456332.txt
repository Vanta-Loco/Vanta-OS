1. BUILD A REUSABLE VANTA SIGNAL SYSTEM
Create reusable components/utilities for controlled glitch and transmission effects.
Suggested concepts:
VantaSignal
SignalGlitch
TransmissionOverlay
CRTFrame
SignalNoise
GlitchText

The system should be able to trigger:
- brief RGB separation
- horizontal image displacement
- tiny frame-offset duplication
- scanline disturbance
- short static bursts
- temporary brightness/contrast jumps
- text corruption
- signal bars / transmission labels
These effects should be short and intentional.
2. GLITCHES MUST BE EVENT-BASED
Do NOT make the entire website constantly glitch.
Trigger signal events at meaningful moments:
- entering a page
- switching between major Vanta sections
- opening a Transmission
- hovering or focusing a special media item
- clicking an ENTER or system-style button
- occasional low-frequency idle signal event
Good example:
click WORLDS
↓
80ms RGB split
↓
horizontal tear
↓
environmental state transitions
↓
image stabilizes

Total disturbance should usually stay under roughly:
100–350ms

It should feel like the signal briefly lost synchronization.
