CORE CONCEPT
Vanta Marketplace is an underground creative-services marketplace for Members and creators.
It should eventually allow artists, producers, designers, photographers, models, writers, engineers, stylists and developers to offer creative services inside the Vanta ecosystem.
It should feel more like creative classifieds / community collaboration than Fiverr.
Every listing must belong to a real Vanta Member.

ROOM ASSOCIATION
A listing may optionally be associated with an existing Vanta Room.
This is important because later the Room's Listings tab will display Marketplace listings connected to that Room.
Do not modify the existing Rooms tables.
Do not add Marketplace columns to rooms.
The Marketplace listing should simply contain nullable:
room_id
referencing the existing Room.
For Phase 1, only allow a Member to associate a listing with a public Room they are currently a member of.
Do not build private-Room Marketplace behavior yet.

API ROUTES
Add the minimum isolated Marketplace API routes.
Browse listings
GET /api/marketplace
Public.
Return active listings with useful creator information such as username.
Support optional query filters where cleanly possible:
category
city
delivery mode
room ID
Do not build complex search yet.
Listing detail
GET /api/marketplace/:id
Public for active listings.
Return:
listing information
creator username/identity information already safely available
associated Room identity if present
Do not expose private user information.
Create listing
POST /api/marketplace
Authenticated Member only.
Validate:
title
description
category
price type
delivery mode
optional price
optional city
optional Room association
If a room_id is provided:
Room must exist
Room must be public
creator must currently be a member of that Room
Update own listing
PATCH /api/marketplace/:id
Only the creator who owns the listing may edit it.
Delete/close own listing
Prefer:
DELETE /api/marketplace/:id
Rather than permanently destroying history, it may set the listing status to closed if that better matches the existing project patterns.
Only the listing creator may perform this action.
Do not add admin Marketplace moderation yet.
SECURITY / DATA RULES
A Member must never edit another Member's listing.
A Member must never close another Member's listing.
A Member must not associate a listing with a Room they have not joined.
Guests cannot create listings.
Do not trust creator_user_id from the browser; derive the creator from authenticated currentUser.
Validate enum-like values server-side.
Keep listing descriptions plain text for Phase 1.
NO FAKE MARKETPLACE CONTENT
Do not seed fake creators.
Do not seed fake Marketplace listings.
Marketplace may initially show an empty state until real Members create listings.
The existing official Rooms should remain unchanged.
