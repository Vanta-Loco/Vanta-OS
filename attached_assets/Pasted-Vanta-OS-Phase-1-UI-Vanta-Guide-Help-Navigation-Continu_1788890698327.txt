Vanta OS — Phase 1 UI: Vanta Guide / Help + Navigation
Continue in Free Mode. Do not switch to Power.
The authenticated Vanta Dashboard and NEXT MOVE system are complete.
This task is ONLY to add a lightweight global Vanta Guide that helps Members understand and navigate Vanta.
Do not build AI/chat functionality yet.
Do not change backend architecture, authentication, database schema, or existing Vanta systems.
Goal
Create a global Vanta OS help/navigation interface that lets a Member quickly answer:
Where do I go?
What does this part of Vanta do?
How do I perform a common action?
It should feel like an OS command/search system rather than a generic FAQ page.
1. Global Vanta Guide
Add a global action called:
VANTA GUIDE
or:
GUIDE
Make it accessible from the existing authenticated Vanta OS shell/header.
Also support:
⌘K on Mac
and:
Ctrl+K on Windows
to open it.
Do not interfere with typing inside normal text inputs/editors.
2. Guide interface
Open as a centered command palette / system overlay.
Include:
search/input field
navigation results
common actions
short contextual explanations
It should close with:
Escape
close button
selecting a navigation result
Preserve keyboard accessibility.

4. Help intents
Add lightweight rule-based answers for common questions.
Examples:
What is Passport?
→ Passport is your identity across Vanta.
Action:
Open Passport
What are Rooms?
→ Rooms are creative spaces and communities inside Vanta.
Action:
Browse Rooms
How do I become a Creator?
→ explain that the Member activates an existing Creator Profile.
Action:
Creator Profile
How do I add my work?
→ Creator Profile → Work → Add Work.
Action:
Manage Work
What is Certified Creator?
→ explain that certification is granted by Vanta/Admin and cannot be self-assigned.
Do NOT claim there is currently an application process unless one exists.
Where do I find producers/designers/etc.?
→ Marketplace.
Where do I find communities?
→ Rooms.
Where do I play sports?
→ Vanta Play.
Where is the city?
→ World Alpha.
Where is Vanta content/news?
→ Transmission.
5. Context-aware suggestions
For authenticated Members, use already available state where practical.
Examples:
If no Creator Profile:
Activate Creator Profile
If Creator Profile exists but Work is empty:
Add your first Work
If no Rooms joined:
Find a Room
Do not duplicate the whole Dashboard NEXT MOVE system.
These should simply improve Guide results.
Do not make additional backend systems for recommendations.
6. Search behavior
Keep search local/rule-based for Phase 1.
Search:
command names
aliases
keywords
help questions
Use forgiving matching where easy.
Exact AI semantic search is NOT required.
Do not call OpenAI or another external AI provider.
7. Result types
Clearly distinguish:
GO TO
for navigation
HOW TO
for instructions
ABOUT
for explaining Vanta concepts
Keep answers short.
The Guide should help people move through Vanta rather than become a documentation encyclopedia.
8. Empty search
When first opened, show useful shortcuts such as:

Passport

Creator
Marketplace
World
And:

9. No-result state
If nothing matches:
No Vanta command found.
Suggest a few core destinations.
Do not invent an AI answer.
10. Visual direction
Make it feel like:
Vanta OS command console
early-2000s system utility
underground digital index

generic SaaS search modal
Use the existing Vanta UI language.

Results must be easy to tap.
No horizontal overflow.
Keyboard shortcut behavior is desktop-only where appropriate.
